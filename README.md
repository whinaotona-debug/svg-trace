# Scratch SVG Paint

ベクターで描けるペイントツールです。ペンや図形の編集に加えて、画像アップロード / AI生成から Gemini で SVG に変換し、キャンバスへ取り込めます。

**公開サイト:** https://whinaotona-debug.github.io/svg-trace/

## できること

- フリーハンド（自動で滑らかなパス化）、直線、四角形、円
- 選択して移動・拡大縮小・回転、色と線の太さの変更
- 最前面 / 最背面、削除、Undo、全消去、SVG保存
- 画像または AI 生成画像をベクター化してキャンバスに載せる

## 使い方

1. サイトを開くと、まずキャンバスが出ます
2. 描画は左のツールバーから
3. 画像から取り込む場合は、上の「画像から取込」→ アップロードまたはAI生成 → キャンバスへ戻る

APIキーはブラウザの localStorage にだけ保存されます。GitHub には含めません。

ローカルでキーを自動入力したい場合は `config.example.js` を `config.local.js` にコピーしてください。
