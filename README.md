# Scratch SVG Paint

ベクターで描けるペイントツールです。ペンや図形の編集に加えて、画像アップロード / AI生成からローカルトレースボットで SVG に変換し、キャンバス中央へ取り込めます。

**公開サイト:** https://whinaotona-debug.github.io/svg-trace/

## できること

- フリーハンド（自動で滑らかなパス化）、直線、四角形、円
- 選択して移動・拡大縮小・回転、色と線の太さの変更
- グループ化、重ね順、反転、削除、Undo、SVG保存
- 画像または AI 生成画像を色面トレースしてキャンバス中央に載せる

## 使い方

1. サイトを開くと、まずキャンバスが出ます
2. 描画は左のツールバーから
3. 画像から取り込む場合は、上の「画像から取込」→ アップロードまたはAI生成 →「トレースしてキャンバスへ」
4. 取り込み画面の「キャンバスへ戻る」でいつでもキャンバスに戻れます

変換はブラウザ内のトレースボットが行います。APIキーは不要です。
